# Edge Alert — Customer Journey

## Step 1: Discovery
Customer finds the Edge Alert landing page via GitHub Pages, social media, or referral.
- Landing page: `landing/index.html` (served via GitHub Pages or edge_server.py at `/`)
- Accuracy dashboard visible publicly: `accuracy_dashboard.html`

## Step 2: Choose a Plan
- **Basic ($39/mo):** Crypto signals via Telegram + daily digest email
- **Pro ($79/mo):** All signals (crypto + sports) in real-time via Telegram, daily digest email, JSON API access, full accuracy dashboard

## Step 3: Subscribe via Stripe
Customer clicks "Subscribe" button on landing page → redirected to Stripe Checkout.
- Basic: `https://buy.stripe.com/8x2cN72UBanhgjN93r00000`
- Pro: `https://buy.stripe.com/3cIbJ3fHn2UP4B50wV00001`

## Step 4: Payment Completes → Automated Onboarding
Stripe fires `checkout.session.completed` webhook → `edge_server.py` handles:
1. Customer record created in SQLite (`customer_db.py`)
2. Unique Telegram invite link generated (member_limit=1) via `telegram_manager.py`
3. Welcome email sent with: Telegram invite link, dashboard URL, billing portal link (`email_service.py`)
4. Event logged to AUDIT_LOG.md

Customer is redirected to `/welcome` page with setup instructions.

## Step 5: Join Telegram Channel
Customer clicks the unique Telegram invite link from their welcome email.
- Invite is single-use (member_limit=1)
- Customer joins the Edge Alert Signals channel

## Step 6: Receive Signals
- **Basic tier:** Crypto signals via Telegram + daily digest email at 8am ET
- **Pro tier:** All signals (crypto + sports) in real-time via Telegram + daily digest email
- Signals generated by `edge_engine.py`, formatted by `formatter.py`, delivered by `telegram_bot.py`
- Daily digest compiled from `signals.jsonl`, sent via `email_service.py`

## Step 7: Monitor Accuracy
Customer can check signal performance at `/dashboard` (accuracy_dashboard.html).
- Overall accuracy, by market type, by confidence tier
- Updated after every market settlement via `accuracy_tracker.py`

## Step 8: Manage Billing
Customer manages subscription via Stripe billing portal.
- Access via `/billing/portal` or link in welcome email
- Can update payment method, change plan, or cancel

## Step 9: Cancellation Flow
If customer cancels (via Stripe portal):
1. Stripe fires `customer.subscription.deleted` webhook
2. Customer record updated to "cancelled"
3. Telegram invite link revoked
4. Customer removed from Telegram channel (if chat_id known)
5. Cancellation confirmation email sent with period end date

## Step 10: Payment Failure
If payment fails:
1. Stripe fires `invoice.payment_failed` webhook
2. Customer marked as "past_due"
3. Payment failure email sent with link to update payment method
4. Signal delivery paused until payment resolved

## Edge Cases
- **Telegram invite fails:** Logged for manual follow-up, email includes note to contact support
- **Email bounces:** Logged in SMTP error handler, customer can still use Telegram invite from welcome page
- **Resubscribe:** Existing customer record reactivated, new Telegram invite generated
- **Tier upgrade/downgrade:** Handled by `customer.subscription.updated` webhook, tier updated in DB
